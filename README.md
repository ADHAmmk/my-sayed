# دفتر البيانات الخاص

تطبيق عربي محلي لإدارة أربعة أقسام: عيادات جامعة المنصورة، مواقع هامة، الأمن العام، وكلمات مرور هامة.

## التشغيل

شغّل خادم ملفات محليًا من مجلد المشروع، ثم افتح الموقع عبر `localhost` في المتصفح (لا تفتحه مباشرةً كملف `file://`). في VS Code يمكنك استخدام إضافة **Live Server**. أو على Windows شغّل الأمر التالي إذا كان Python مثبتًا:

```powershell
python -m http.server 8000
```

لا يحتاج التطبيق إلى خادم بيانات أو اتصال بالإنترنت. استخدم متصفحًا حديثًا يدعم Web Crypto.

## تثبيت التطبيق وبدء العمل بدون اتصال

المشروع أصبح تطبيقًا تقدميًا (PWA) ويمكن تثبيته من متصفح Chrome أو Edge على Android بعد رفعه على رابط HTTPS آمن. عند التثبيت يخزّن التطبيق الواجهة والصور في خدمة العامل، ويعمل بعد انقطاع الإنترنت.

- لا ترفع المشروع بمجلدات خاصة أو `file://`.
- استخدم HTTPS دائمًا لأن تسجيل العامل والتشفير لا يعملان بصورة موثوقة على HTTP.
- لتنزيله على Android: افتح الموقع في Chrome، افتح القائمة، واختر **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.

## الاستعداد لـ Google Play

تم تجهيز المشروع ليعمل على الرابط الإنتاجي: `https://my-sayed.vercel.app/` وبحزمة مقترحة: `com.mrsayed.privateNotebook`.

لنشر نسخة متجر Android يلزم Android App Bundle موقّع بحساب Google Developer. المتطلبات النهائية:

1. رفع أحدث نسخة من هذا المشروع إلى Vercel والتأكد من ظهور `manifest.json` و`sw.js`.
2. إنشاء مشروع Trusted Web Activity مرتبط بنفس النطاق وبحزمة التطبيق.
3. إنشاء مفتاح توقيع Play وتوليد بصمة SHA-256 لإضافتها في `/.well-known/assetlinks.json`.
4. رفع ملف `.aab` إلى Google Play Console واكمال قائمة الخصوصية والفئة والإعلانات والتصنيف العمري.

## التخزين والخصوصية

- تُشفّر السجلات باستخدام AES-GCM بمفتاح مشتق من كلمة المرور الرئيسية عبر PBKDF2-SHA-256.
- لا تُخزّن كلمة المرور الرئيسية، ولا تُرسل البيانات إلى خادم.
- أنشئ كلمة مرور قوية لا تقل عن 12 حرفًا، واحتفظ بها بأمان. لا توجد آلية لاستعادة كلمة مرور منسية.
- البيانات محفوظة في تخزين المتصفح على هذا الجهاز؛ مسح بيانات الموقع أو فقد الجهاز قد يؤدي إلى فقدها. لا تستخدم التطبيق على جهاز مشترك أو غير موثوق.
