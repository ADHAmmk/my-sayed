# دفتر البيانات الخاص

تطبيق عربي محلي لإدارة أربعة أقسام: عيادات جامعة المنصورة، مواقع هامة، الأمن العام، وكلمات مرور هامة.

## التشغيل

شغّل خادم ملفات محليًا من مجلد المشروع، ثم افتح الموقع عبر `localhost` في المتصفح (لا تفتحه مباشرةً كملف `file://`). في VS Code يمكنك استخدام إضافة **Live Server**. أو على Windows شغّل الأمر التالي إذا كان Python مثبتًا:

```powershell
python -m http.server 8000
```

لا يحتاج التطبيق إلى خادم بيانات أو اتصال بالإنترنت. استخدم متصفحًا حديثًا يدعم Web Crypto.

## التخزين والخصوصية

- تُشفّر السجلات باستخدام AES-GCM بمفتاح مشتق من كلمة المرور الرئيسية عبر PBKDF2-SHA-256.
- لا تُخزّن كلمة المرور الرئيسية، ولا تُرسل البيانات إلى خادم.
- أنشئ كلمة مرور قوية لا تقل عن 12 حرفًا، واحتفظ بها بأمان. لا توجد آلية لاستعادة كلمة مرور منسية.
- البيانات محفوظة في تخزين المتصفح على هذا الجهاز؛ مسح بيانات الموقع أو فقد الجهاز قد يؤدي إلى فقدها. لا تستخدم التطبيق على جهاز مشترك أو غير موثوق.
